# NixOS configuration

My personal NixOS setup, as a flake. One host (`tuxedo`), a handful of
shared modules, no home-manager — everything lives at the system level.

## Layout

```
flake.nix                 inputs + nixosConfigurations
hosts/
  tuxedo/
    default.nix           host: hostname, bootloader, module imports
    hardware-configuration.nix   generated by nixos-generate-config
modules/
  core.nix                nix daemon, networking, locale, shell
  hardware.nix            bluetooth, pipewire, upower, keyd
  desktop.nix             hyprland/niri, sddm, fonts, session vars
  packages.nix            system profile packages
  users.nix               user accounts
```

## Hosts

| Host     | Hardware              | Boot          | Root |
| -------- | --------------------- | ------------- | ---- |
| `tuxedo` | Intel laptop (x86_64) | systemd-boot  | ext4 |

## Usage

Rebuild and switch:

```sh
sudo nixos-rebuild switch --flake .#tuxedo
```

Build without activating (useful for checking a change compiles):

```sh
nixos-rebuild build --flake .#tuxedo
```

Test until reboot, or stage for the next boot:

```sh
sudo nixos-rebuild test --flake .#tuxedo
sudo nixos-rebuild boot --flake .#tuxedo
```

Update all flake inputs (or just one):

```sh
nix flake update
nix flake update nixpkgs
```

Garbage collect old generations:

```sh
sudo nix-collect-garbage --delete-older-than 14d
```

## Flake inputs

- **nixpkgs** — `nixos-unstable`
- **[apple-fonts](https://github.com/Lyndeno/apple-fonts.nix)** — San Francisco fonts
- **[aven](https://github.com/raine/aven)** — local-first TUI task manager
- **[workmux](https://github.com/raine/workmux)** — git worktree + tmux workflow tool

All three follow the same `nixpkgs` as the system.

## What's configured

- **Desktop:** Hyprland (with UWSM, the default session) and Niri, both on
  Wayland, behind SDDM. Nerd Fonts plus SF Pro as the default sans.
- **Locale:** `en_US.UTF-8` with Finnish regional formats, `fi` console and
  X11 keymap (`nodeadkeys`), `Europe/Helsinki`.
- **Audio/input:** PipeWire (ALSA + Pulse), Bluetooth with battery reporting,
  and keyd mapping Caps Lock to Ctrl on hold / Esc on tap.
- **Shell:** fish, with NixOS' default shell aliases cleared.
- **Unfree packages** are allowed.

## Adding a host

1. Run `nixos-generate-config --show-hardware-config > hosts/<name>/hardware-configuration.nix`
   on the target machine.
2. Add `hosts/<name>/default.nix` importing the hardware config and the
   modules you want, and set `networking.hostName`.
3. Register it under `nixosConfigurations` in `flake.nix`.

## Notes

`system.stateVersion` is pinned to the release the machine was installed with
and should not be bumped on upgrade.
